# 넘버퀘스트

레벨이 올라갈수록 어려워지는 한국어 계산 게임입니다. 정답 5개마다 레벨이 올라가며 레벨 3부터 뺄셈, 5부터 곱셈, 8부터 나눗셈이 등장합니다. 오답은 같은 문제를 다시 풀 수 있고 최고 점수는 브라우저에 저장됩니다.

## 실행

Node.js 18 이상과 Python 3를 사용합니다. 추가 패키지 설치는 필요 없습니다.

```sh
cd /workspace/number
npm start
```

기본 포트는 3000입니다. 테스트는 `npm test`로 실행합니다. Google Fonts에 연결하지 못해도 시스템 글꼴로 작동합니다.
